# Standard SOP Template

Every individual SOP should eventually follow a consistent structure:

1. **SOP Code**
2. **SOP Title**
3. **Department / Responsible Unit**
4. **Effective Date**
5. **Revision Number**
6. **Purpose**
7. **Scope**
8. **Definitions**, where applicable
9. **Responsibilities**
10. **Required Materials / Equipment / Systems**
11. **Pre-Procedure Checks**
12. **Detailed Procedure**
13. **Service Standards / Quality Standards**
14. **Safety \& Compliance Requirements**
15. **Guest-Service Considerations**
16. **Escalation / Exception Handling**
17. **Required Forms \& Records**
18. **Related SOPs**
19. **Key Performance Indicators (KPIs)**, where applicable
20. **Revision History**
21. **Approval / Authorization**

## Coding Convention

Use permanent department-based codes rather than renumbering the entire manual whenever a new SOP is inserted.

Examples:

* `SOP-FO-01` — Front Office
* `SOP-HK-01` — Housekeeping
* `SOP-FB-01` — Food \& Beverage
* `SOP-FH-01` — Function Hall
* `SOP-FM-01` — Facilities / Maintenance
* `SOP-SS-01` — Safety / Security
* `SOP-HR-01` — Human Resources
* `SOP-AD-01` — Administration
* `SOP-DS-01` — Digital Systems

This allows new procedures to be added without disrupting existing SOP codes.
