# Staffing \& Organizational Plan: Marcela Hotel \& Resort

## 1\. Property Meta \& Scope

* **Property Name:** Marcela's Hotel \& Resort
* **Location:** Gamay, Northern Samar, Philippines
* **Capacity:** 30 Rooms | Restaurant | Function Hall | Swimming Pool
* **Operating Framework:** Lean Cross-Functional Structure (11 Regular Core Staff + 14–18 Flexible On-Call Pool)

\---

## 2\. Headcount \& Roster Allocation

### A. Core Regular Positions (11 Headcount)

1. `POS-01`: General Manager / Resort Manager (1 FTE)
2. `POS-02`: Operations \& Front Office Supervisor (1 FTE)
3. `POS-03`: Front Desk \& Guest Services Officer (1 FTE)
4. `POS-04`: Night Auditor \& Guest Operations Night Staff (1 FTE)
5. `POS-05`: Housekeeping \& Laundry Lead (1 FTE)
6. `POS-06`: Housekeeping / Room Attendant A (1 FTE)
7. `POS-07`: Housekeeping / Room Attendant B (1 FTE)
8. `POS-08`: Cook / Kitchen Lead (1 FTE)
9. `POS-09`: Assistant Cook / Kitchen Steward (1 FTE)
10. `POS-10`: Maintenance \& Pool Technician (1 FTE)
11. `POS-11`: Admin, Finance \& Purchasing Officer (1 FTE)

### B. Flexible On-Call \& Contracted Roster (14–18 Pool)

* `FLX-01`: Pool Lifeguards (2 On-Call Roster)
* `FLX-02`: Banquet Servers \& Bartenders (4–5 On-Call Roster)
* `FLX-03`: Housekeeping \& Laundry Relief (3–4 On-Call Roster)
* `FLX-04`: Security Personnel (Outsourced / Contracted 24/7)

## 3\. Position Specifications \& SOP Cross-Mappings

### POS-01: General Manager / Resort Manager

* **Reports To:** Owner / Proprietor
* **Supervises:** POS-02, POS-05, POS-08, POS-10, POS-11
* **Primary Duties:** Commercial sales, event quotations/contracts, GOP management, overall operations.
* **Secondary / Cross-Functional:** Emergency Incident Command (`SOP-SS-14`), High-level Guest Service Recovery (`SOP-FO-11`).
* **KPIs:** GOP target met, Guest Satisfaction >90%, Labor cost ratio.

### POS-02: Operations \& Front Office Supervisor

* **Reports To:** POS-01
* **Supervises:** POS-03, POS-04, FLX-01 to FLX-03
* **Primary Duties:** FO operations, weekly scheduling (`SOP-HR-06`), triggering on-call roster activations based on occupancy/events.
* **Secondary / Cross-Functional:** Event registration oversight (`SOP-FH-09`), Level-2 guest complaint resolution (`SOP-FO-11`).
* **KPIs:** Check-in speed <3 min, On-call activation precision, zero unhandled escalations.

### POS-03: Front Desk \& Guest Services Officer

* **Reports To:** POS-02
* **Supervises:** None
* **Primary Duties:** Check-in/out (`SOP-FO-04` to `08`), PMS/OTA reservation handling (`SOP-FO-02`, `SOP-DS-10`), cashiering (`SOP-FO-15`).
* **Secondary / Cross-Functional:** F\&B order entry during off-peak shifts (`SOP-FB-05`), event inquiries (`SOP-FH-02`).
* **KPIs:** 100% reservation entry accuracy, zero cash drawer discrepancies.

### POS-04: Night Auditor \& Guest Operations Night Staff

* **Reports To:** POS-02
* **Supervises:** FLX-04 (Night Security Oversight)
* **Primary Duties:** System day-end audit \& revenue reconciliation (`SOP-FO-22`, `SOP-AD-09`), night check-ins (`SOP-FO-24`).
* **Secondary / Cross-Functional:** CCTV/security monitoring (`SOP-SS-10`, `SOP-SS-12`), early breakfast prep staging (`SOP-FB-01`).
* **KPIs:** Daily audit balance accuracy, 0 unreconciled night entries.

### POS-05: Housekeeping \& Laundry Lead

* **Reports To:** POS-01
* **Supervises:** POS-06, POS-07, FLX-03
* **Primary Duties:** Room inspection release (`SOP-HK-05`), linen/towel inventory \& laundering control (`SOP-HK-16` to `18`), chemical safety (`SOP-HK-22`).
* **Secondary / Cross-Functional:** Public area sanitation inspection (`SOP-HK-13`), event space reset oversight (`SOP-FH-19`).
* **KPIs:** 100% inspection pass rate, linen turnover speed.

### POS-06 \& POS-07: Housekeeping / Room Attendants

* **Reports To:** POS-05
* **Supervises:** None
* **Primary Duties:** Room cleaning \& turnover (`SOP-HK-02` to `04`), public area cleaning (`SOP-HK-13`), in-house laundry operation (`SOP-HK-16`).
* **Secondary / Cross-Functional:** Function hall clean/reset (`SOP-FH-19`), pool deck cleaning (`SOP-HK-14`).
* **KPIs:** 25–30 min room cleaning cycle, cleanliness score >90%.

### POS-08: Cook / Kitchen Lead

* **Reports To:** POS-01
* **Supervises:** POS-09, FLX-02 (Kitchen Helpers)
* **Primary Duties:** Menu execution, food prep/plating (`SOP-FB-07`, `08`), kitchen hygiene/HACCP (`SOP-FB-12`), FIFO inventory receiving (`SOP-FB-14` to `18`).
* **Secondary / Cross-Functional:** Event catering production (`SOP-FB-25`).
* **KPIs:** Food cost %, kitchen ticket time <20 min, hygiene audit >95%.

### POS-09: Assistant Cook / Kitchen Steward

* **Reports To:** POS-08
* **Supervises:** None
* **Primary Duties:** Dishwashing/sanitation (`SOP-FB-19`), raw food prep (`SOP-FB-07`), cold storage temperature logging (`SOP-FB-17`).
* **Secondary / Cross-Functional:** Off-peak breakfast service \& F\&B cashiering (`SOP-FB-09`, `SOP-FB-22`).
* **KPIs:** 100% temp log compliance, 0 dishware breakage/shortage.

### POS-10: Maintenance \& Pool Technician

* **Reports To:** POS-01
* **Supervises:** External Service Contractors
* **Primary Duties:** Facilities/HVAC/plumbing PM (`SOP-FM-01` to `06`), generator/pump maintenance (`SOP-FM-07`, `08`), pool chemical/vacuuming care (`SOP-FM-18` to `21`).
* **Secondary / Cross-Functional:** Pre/post-typhoon fortification and cleanup (`SOP-SS-16`, `20`).
* **KPIs:** 100% generator start readiness, pool chemical balance adherence, maintenance resolution <2 hrs.

### POS-11: Admin, Finance \& Purchasing Officer

* **Reports To:** POS-01
* **Supervises:** None
* **Primary Duties:** Bookkeeping, AP/AR, petty cash (`SOP-AD-07`, `08`), payroll \& timekeeping (`SOP-HR-05`, `07`), procurement/receiving (`SOP-AD-03` to `06`), government permits (`SOP-AD-12`).
* **Secondary / Cross-Functional:** Daily revenue verification (`SOP-AD-09`).
* **KPIs:** On-time payroll, 0 permit penalties, financial report precision.
